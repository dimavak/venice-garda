# Венецыя і Гарда, 4–7.10.2026

Статычная старонка з планам паездкі. Адзін файл `index.html`, без зборкі.

## Як апублікаваць на GitHub Pages

1. Стварыце на github.com новы публічны рэпазіторый, напрыклад `venice-garda`.
2. Add file → Upload files → перацягніце `index.html` (і гэты README) → Commit changes.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Праз 1–2 хвіліны старонка будзе па адрасе `https://<ваш-лагін>.github.io/venice-garda/`.
